# Surgical asset attribution

The converted patient-side surgical cart model is adapted from **Robotic System A01** by NVIDIA, from the
[`nvidia/simready-assets` dataset](https://huggingface.co/datasets/nvidia/simready-assets), package ID
`simready.hf.nvidia.simready-assets.robotic_system_a01.2026.10.09_154641182368`.

The source package declares **CC BY 4.0**. The model was converted from USD to MuJoCo XML and OBJ meshes for this
simulation; materials, some internal joints, and per-asset friction were not preserved. The license text shipped
with the source package is included as [`ASSET_LICENSE.txt`](ASSET_LICENSE.txt).
