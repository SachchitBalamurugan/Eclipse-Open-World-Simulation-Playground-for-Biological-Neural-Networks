ECLIPSE

How Eclipse trains a robot with a biological neural network

Six phases, from first contact to the sun returning. All controllers are simulated Izhikevich neuron cultures — no living neurons are used in simulation.

01 · First contact

Import robot

Drop in MJCF, URDF or a zip with meshes. MuJoCo loads it; Eclipse finds the end-effector, adds motors if missing and maps the reachable workspace.

02 · Partial

Configure BNN

1,024 Izhikevich neurons on an 8×8 electrode array. Choose the learning rule (Teach or Frozen control), learning rate and seed.

03 · Deeper

Choose platform

Local CPU with a live 3D view, or a Freestyle VM fleet: N Linux VMs training N cultures at the same time.

04 · Totality

Train

Closed loop every step: robot error → stimulation → spikes → joint moves, then teaching stimulation. Frames, spikes and errors stream live.

05 · Diamond ring

Evaluate

10 held-out targets with learning switched off, before and after training. Every run is saved for replay in 3D or download.

06 · Third contact

Deploy

Export the closed-loop protocol as a bundle a lab can run on a living culture, and dry-run it against a mock electrode array.

Inside phase 4 · one control step

Encoder

End-effector error (x, y, z) → pulse counts on sensory electrodes

→

Simulated culture

1,024 Izhikevich neurons · STDP synapses · 64-electrode MEA

→

Decoder

Spike counts in +/– motor pools per joint → joint position change

Teach rule (paired stimulation): after the move, replay the sensory pattern and stimulate the motor pool that should have fired 3 ms later, so spike-timing plasticity strengthens the correct pathway. Frozen = no plasticity, the control.
